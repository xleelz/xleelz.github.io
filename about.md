I'm Lee Bethay, a software engineer at **OpenRelay**. Previously, I was a Software Development Engineer (SDE) at **Amazon Web Services**.

I love system design: figuring out how data moves through a system, where it can fail, and how to make it keep working when it does. This blog is where I write about those problems and what I've learned solving them.

Outside of work, I practice martial arts and am always learning something new.

## Recommended reading

If you're interested in system design, start with [*Designing Data-Intensive Applications*](https://dataintensive.net/) by Martin Kleppmann. It's my go-to recommendation for understanding how real-world data systems work and the trade-offs behind them.
